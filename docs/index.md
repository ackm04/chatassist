## ✨ What it does

ChatAssist lets you embed **any chat experience** into your WordPress site — just paste a URL. Whether you're using an n8n workflow, a custom AI chatbot, or a third-party service, you're live in under a minute.

No coding required. No vendor lock-in. Works with anything that has a webhook URL.

---

## 🚀 Features

| Feature | Details |
|---|---|
| **Plug-and-play** | Drop any webhook URL and the widget appears immediately |
| **Pre-chat lead form** | Capture name, email, phone before the chat opens |
| **Smart display rules** | Show/hide by page, device, time, day, user role, or geo |
| **WooCommerce-aware** | Target Shop, Product, Cart, Checkout, and Account pages |
| **Built-in analytics** | Opens, closes, messages, conversions, PDF export |
| **A/B testing** | Split-test chat variants with built-in stats |
| **Multi-widget profiles** | Different chat URLs per page or post |
| **Live preview** | See exactly how your widget looks before saving |
| **Goal & conversion tracking** | WooCommerce orders and custom events |
| **Marketing modal** | Newsletter signup with exit-intent and timed triggers |
| **PWA + push** | Installable web-app manifest and Web Push support |
| **Native integrations** | Intercom, Crisp, Drift, Tawk.to, LiveChat |
| **Webhooks** | Outbound events to Slack, Discord, HubSpot, Salesforce |

| **Fully translatable** | `.pot` file included |

## 📦 Installation

**From WordPress.org (recommended)**

1. Go to **WP Admin → Plugins → Add New**
2. Search for **"ChatAssist by Ajay"**
3. Click **Install → Activate**
4. Navigate to **ChatAssist by Ajay** in the admin menu

**Quick start**

1. Open **ChatAssist by Ajay** in the WP admin menu
2. Paste your **Chat URL** (any webhook — n8n, AI bot, custom service)
3. Choose a position, color, and icon
4. Save — the widget appears on every page

## 🔗 Works with everything

- **n8n** — paste your workflow webhook URL and go
- **Custom AI chatbots** — any endpoint that accepts HTTP requests
- **Intercom, Crisp, Drift, Tawk.to, LiveChat** — native one-click integrations
- **Zapier, HubSpot, Salesforce** — outbound webhook events
- **Slack & Discord** — real-time chat event notifications

## 🧰 Requirements

- WordPress 6.0 or higher
- PHP 7.4 or higher
- jQuery (bundled with WordPress core)
- HTTPS recommended (required for PWA and push)

---

## 🔐 Security

All admin endpoints are nonce-protected and capability-gated. All user input is sanitized on save and escaped on output. Found a vulnerability? Email **ackm04@gmail.com** — do not open a public issue.
